# Benchkit

Школа коду просто в браузері: редактор із підсвіткою, запуск за секунду, прості пояснення помилок, рівні та бали. Без встановлення й без власного сервера.

## Що і як запускається

| Мова | Як працює |
| --- | --- |
| Python | справжній CPython через [Pyodide](https://pyodide.org) (~10 МБ при першому запуску) |
| JavaScript | ізольований `<iframe sandbox>` із 8-секундним захистом від нескінченних циклів |
| HTML | живий перегляд у пісочниці |
| CSS | перегляд на тестовій розмітці |
| C++, Java, Rust, Go | справжні компілятори у хмарі через [Wandbox](https://wandbox.org) — потрібен інтернет |
| Блоки, SQL | поки що лише редактор (етап 5 і 6) |

Мови з компілятором у хмарі мають поле **«Вхідні дані»** — те, що програма прочитає, наче хтось надрукував на клавіатурі. Перший запуск Rust чи Go може тривати з пів хвилини, тому під час чекання є кнопка **«Скасувати»**.

## Редактор

Monaco Editor (той самий, що у VS Code): підсвітка, автозакриття дужок і лапок, перевірка `Ctrl`+`Enter`. Код кожного файла зберігається у `localStorage` браузера, розмір шрифту регулюється кнопками A− / A+.

## Пояснення помилок

`explain.js` перекладає повідомлення компілятора простою мовою: що сталося і одну-дві поради, як виправити. Працює офлайн, без штучного інтелекту. Повний текст помилки — під вкладкою.

## Школа

Чотири рівні, по три уроки та задачі-боси на кожному. За урок — 10 балів, за боса — 25. Перевірка запускає код і дивиться, чи вивело програма те, що просили. На 25, 50, 75 і 100 % — нове звання.

## Куди потрапляє твій код

Python, JavaScript, HTML і CSS виконуються повністю на твоєму пристрої. Для C++, Java, Rust і Go текст програми надсилається на Wandbox, бо там живуть компілятори; результат повертається назад у браузер. Інші файли нікуди не відправляються.

## Файли

```
index.html    розмітка й шаблони сторінок
theme.css     Material Design 3 Expressive: кольори, форми, рух
styles.css    інтерфейс
i18n.js       українська і англійська
explain.js    пояснення помилок
school.js     рівні, уроки, бали
app.js        мови, запуск, збереження коду
.nojekyll     щоб GitHub Pages не ігнорував файл із підкресленням
```

У репозиторії немає залежностей: Monaco Editor і Pyodide підвантажуються з CDN.

## Локально

Просто двічі клацніть `index.html` — усе працює і з диска. Або запустіть будь-який статичний сервер, наприклад:

```
python -m http.server 8000
```

і зайти на http://localhost:8000

## Публікація на GitHub Pages

1. Створити репозиторій `benchkit` на github.com (кнопка **New repository**).
2. Завантажити в нього файли вище (кнопка **Add files → Upload files**).
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, branch `main`, folder `/ (root)`, **Save**.
4. Через хвилипу сайт доступний за адресою `https://<ваш-акаунт>.github.io/benchkit/`.

## Гарячі клавіші

- `Ctrl` / `⌘` + `Enter` — запустити
- `Ctrl` / `⌘` + `S` — завантажити файл
